# 应用图标

使用内置图像生成工具（builtin 模式）创建，无外部参考图。设计为薄荷绿色循环箭头与勾选符号，深绿灰色圆角方形底，代表逐轮补测与覆盖率验证。

资产：

- `apps/desktop/build/app-icon-source.png`：1280 × 1280 生成原图，可供后续编辑。
- `apps/desktop/public/app-icon.png`：256 × 256，用于标题栏、侧栏与页面 favicon。
- `apps/desktop/build/icon.ico`：包含 16、24、32、48、64、128、256 像素尺寸，用于 Electron 窗口、Windows EXE 和 NSIS 安装包。

生成后仅做格式转换及尺寸缩放，没有二次绘制。

生成提示词的设计要求：为 Coverage Loop 桌面应用创建专业应用图标；独立圆角方形深绿灰色底；中心以柔和薄荷绿色循环箭头构成 C 形，结合清楚的勾选符号；简洁几何形状、适合小尺寸、轻微立体层次、透明外部背景；无文字、无水印、无展示样机、无额外图标。
